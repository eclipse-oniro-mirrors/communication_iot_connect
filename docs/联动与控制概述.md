# 联动与控制概述

## 一、系统架构

![imagepng](https://raw.gitcode.com/user-images/assets/9584680/1c2c0fde-b28b-4d5f-a107-c97a51c1606d/image.png)

### 1.1 核心组件

| 组件                                     | 说明                    |
| -------------------------------------- | --------------------- |
| 鸿蒙生态云平台(HarmonyConnect Cloud)          | 网络统一组织和调用资源，提供服务      |
| 鸿蒙生态终端(HarmonyConnect Device)          | 连接到互联网络中可执行控制指令的电子化产品 |
| 鸿蒙生态配置器(HarmonyConnect Configurator)   | 配置应用终端并接入家庭局域网络的逻辑实体  |
| 鸿蒙生态通用互联APP(HarmonyConnect APP)        | 运行在智能设备中用于生态设备管理的应用程序 |
| 鸿蒙生态桥接设备(HarmonyConnect Bridge Device) | 将非IP设备接入互联网络的设备       |

### 1.2 控制模式

| 模式          | 说明                   |
| ----------- | -------------------- |
| 点到点本地控(P2P) | 手机与设备之间的直接控制，无需云平台支持 |
| 局域网本地控      | 外网断开时，通过家庭局域网发送控制命令  |
| 远程控制        | 通过云平台实现远程设备控制        |

## 二、标准

### 2.1 统一设备接入与控制接口标准

统一互联在生态设备与设备、APP与设备、以及设备与云平台之间，定义并实现了一套完整的标准交互接口。通过将设备配网、数据传输、设备控制和设备管理等核心流程标准化。如图所示，这一框架构建了一个共通的通信语言和交互范式。对用户而言，这意味着极简的配网流程和无缝的跨设备操控体验；对开发者与厂商而言，则能屏蔽底层复杂性，专注于产品功能创新，从而快速融入并共建一个开放、协同且可规模化扩展的智能生态系统。

接口说明

| 接口名称  | 通讯协议                         | 接口说明                                                                                   |
| ----- | ---------------------------- | -------------------------------------------------------------------------------------- |
| IF1.1 | BLE Adv广播 JSON Over BLE GATT | 通用互联APP与BLE设备通信接口，用于设备发现，连接，配网，点到点本地控。如果设备为标准BLE Profile，则使用标准Profile通信。               |
| IF1.2 | Wi-Fi Beacon广播 CoAP Over UDP | 通用互联APP与Wi-Fi设备通信接口，用于设备发现，连接，配网，点到点本地控。                                               |
| IF1.3 | CoAP Over UDP                | 通用互联APP与以太网设备通信接口，用于设备发现，连接，配网，点到点本地控。                                                 |
| IF2.1 | CoAP Over TLS CoAP Over TCP  | 资源不受限场景下Wi-Fi设备与云端通信接口，用于设备注册，登录，控制，传输层加密。资源受限场景下Wi-Fi设备与云端通信接口，用于设备注册，登录，控制，消息需要应用层加密 |
| IF2.2 | CoAP Over TLS                | 桥设备与云端通信接口。                                                                            |
| IF2.3 | CoAP Over TLS                | 以太网设备与云端通信接口。                                                                          |
| IF3   | HTTPS MQTT                   | 通用互联APP与云端通信接口。云端向通用互联APP推送消息接口。                                                       |
| IF4.1 | BLE GATT                     | BLE 设备与桥设备通信接口。                                                                        |
| IF4.2 | BLE Mesh                     | BLE Mesh设备与桥设备通信接口。                                                                    |
| IF5   | CoAP Over UDP                | 云断开时，通用互联APP与设备之间本地通信接口，用于局域网本地控。                                                      |

详细介绍请参考查阅鸿蒙生态设备统一互联-接入与控制接口技术标准[《鸿蒙生态设备统一互联 接入与控制接口技术标准》](https://www.giiconsortium.org/2025/post/2506/)。

### 2.2 统一设备物模型标准

物模型又可称为设备模型或数据模型，是物理设备在数字化空间中的标准化抽象与表达，它构成了物联网中设备、云平台与用户应用（如APP）进行双向数据交互的通用语言和核心规范。如下图所示，设备物模型基本组成元素包含服务、事件、特征以及一些“关键信息”。通过这套预定义的模型，生态中的各方无需关心底层复杂的物理协议，只需依据统一的数据格式进行通信，从而实现了不同品牌、品类设备与云端及应用之间的联动与控制。
其中，鸿蒙生态设备统一互联物模型技术标准可以参考[《鸿蒙生态设备统一互联 物模型技术标准》](https://www.giiconsortium.org/2025/post/2502/)。
