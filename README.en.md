# communication_iot_connect

#### Description
响应OpenHarmony生态共建伙伴提出智慧病房、智慧隧道、会议办公等场景的富设备对瘦设备控制的需求。在生态互联互通共建项目中，构建瘦设备上运行的极简连接控制组件：iot_connect，实现在mini/small级别OH设备上的控制和连接。
